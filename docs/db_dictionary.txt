================================================================================
  9. QUESTIONS                                                          [Omar]
================================================================================
  Stores the question bank for all courses.
  Supports two question types:
    MCQ = Multiple Choice (4 options)
    TF  = True/False (2 options)
  Each question carries a point value used by CorrectExam.

  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+
  | Column Name      | Type        | PK | FK | NN | UQ | Default | Check                 | Description                      |
  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+
  | QuestionID       | SERIAL      | Y  |    | Y  |    | auto    |                       | Unique identifier.               |
  |                  |             |    |    |    |    |         |                       | Auto-incremented.                |
  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+
  | CourseID         | INT         |    | Y  | Y  |    |         |                       | FK --> Course.CourseID.          |
  |                  |             |    |    |    |    |         |                       | Course this question belongs to. |
  |                  |             |    |    |    |    |         |                       | ON DELETE RESTRICT.              |
  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+
  | QuestionText     | TEXT        |    |    | Y  |    |         |                       | Full question text.              |
  |                  |             |    |    |    |    |         |                       | Supports Arabic + English.       |
  |                  |             |    |    |    |    |         |                       | Use TEXT, not VARCHAR.           |
  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+
  | Type             | TEXT        |    |    | Y  |    |         | Type IN ('MCQ','TF')  | Question type. Must be exactly   |
  |                  |             |    |    |    |    |         |                       | 'MCQ' or 'TF'. Enforced by CHECK |
  |                  |             |    |    |    |    |         |                       | constraint at column level.      |
  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+
  | Points           | INT         |    |    | Y  |    |         | Points > 0            | Score for a correct answer.      |
  |                  |             |    |    |    |    |         |                       | Must be positive. Used by        |
  |                  |             |    |    |    |    |         |                       | CorrectExam to compute           |
  |                  |             |    |    |    |    |         |                       | TotalGrade.                      |
  +------------------+-------------+----+----+----+----+---------+-----------------------+----------------------------------+


================================================================================
  10. CHOICE                                                            [Omar]
================================================================================
  Stores answer options for each question.
    MCQ questions must have exactly 4 Choice rows.
    TF  questions must have exactly 2 Choice rows (True / False).
  The correct choice is recorded in ModelAnswer.

  +------------------+----------+----+----+----+----+---------+---------------------------+------------------------------------+
  | Column Name      | Type     | PK | FK | NN | UQ | Default | Check                     | Description                        |
  +------------------+----------+----+----+----+----+---------+---------------------------+------------------------------------+
  | OptionID         | SERIAL   | Y  |    | Y  |    | auto    |                           | Unique identifier.                 |
  |                  |          |    |    |    |    |         |                           | Auto-incremented.                  |
  +------------------+----------+----+----+----+----+---------+---------------------------+------------------------------------+
  | QuestionID       | INT      |    | Y  | Y  |    |         |                           | FK --> Questions.QuestionID.       |
  |                  |          |    |    |    |    |         |                           | Question this choice belongs to.   |
  |                  |          |    |    |    |    |         |                           | ON DELETE CASCADE.                 |
  +------------------+----------+----+----+----+----+---------+---------------------------+------------------------------------+
  | OptionText       | TEXT     |    |    | Y  |    |         |                           | Text of the answer option          |
  |                  |          |    |    |    |    |         |                           | (e.g. 'True', 'SELECT * FROM ...'  |
  |                  |          |    |    |    |    |         |                           | Supports Arabic + English.         |
  +------------------+----------+----+----+----+----+---------+---------------------------+------------------------------------+
  | OptionOrder      | INT      |    |    | Y  |    |         | OptionOrder BETWEEN 1     | Display order within its question. |
  |                  |          |    |    |    |    |         | AND 4                     | 1-4 for MCQ, 1-2 for TF.          |
  |                  |          |    |    |    |    |         |                           | Enforced by CHECK constraint.      |
  +------------------+----------+----+----+----+----+---------+---------------------------+------------------------------------+


================================================================================
  11. MODELANSWER                                                       [Omar]
================================================================================
  Stores the single correct answer for each question.
  UNIQUE on QuestionID enforces exactly one model answer per question.
  HIDDEN from the student role at the database level (REVOKE ALL).

  +------------------+----------+----+----+----+----+---------+------------------+----------------------------------------+
  | Column Name      | Type     | PK | FK | NN | UQ | Default | Check            | Description                            |
  +------------------+----------+----+----+----+----+---------+------------------+----------------------------------------+
  | QuestionID       | INT      | Y  | Y  | Y  | Y  |         |                  | FK --> Questions.QuestionID.           |
  |                  |          |    |    |    |    |         |                  | Also acts as PK (one row per           |
  |                  |          |    |    |    |    |         |                  | question). ON DELETE CASCADE.          |
  +------------------+----------+----+----+----+----+---------+------------------+----------------------------------------+
  | CorrectOptionID  | INT      |    | Y  | Y  |    |         |                  | FK --> Choice.OptionID.                |
  |                  |          |    |    |    |    |         |                  | The correct answer option.             |
  |                  |          |    |    |    |    |         |                  | SetModelAnswer must validate that      |
  |                  |          |    |    |    |    |         |                  | this OptionID belongs to the same      |
  |                  |          |    |    |    |    |         |                  | QuestionID. ON DELETE RESTRICT.        |
  +------------------+----------+----+----+----+----+---------+------------------+----------------------------------------+

  |                  |             |    |    |    |    |         |                  | Auto-incremented.                |
  +------------------+-------------+----+----+----+----+---------+------------------+----------------------------------+
  | StudentID        | INT         |    | Y  | Y  |    |         |                  | FK --> Student.StudentID.        |
  |                  |             |    |    |    |    |         |                  | Student who took the exam.       |
  |                  |             |    |    |    |    |         |                  | ON DELETE CASCADE.               |
  +------------------+-------------+----+----+----+----+---------+------------------+----------------------------------+
  | ExamID           | INT         |    | Y  | Y  |    |         |                  | FK --> Exams.ExamID.             |

  |                  |             |    |    |    |    |         |                  | ON DELETE RESTRICT.              |

  +------------------+-------------+----+----+----+----+---------+------------------+----------------------------------+

================================================================================
  APPENDIX C -- DB ROLES & SECURITY
================================================================================

  ROLES
  -----
  admin_role       Created by: Mahdy
                   Access: SUPERUSER / db_owner -- full access to all tables,
                           procedures, and system functions.
                   CREATE ROLE admin_role WITH LOGIN SUPERUSER;

  instructor_role  Created by: Mariam
                   Access: Read/write on course, question, student, and exam
                           tables via stored procedures only.
                   CREATE ROLE instructor_role WITH LOGIN;

  student_role     Created by: Mariam
                   Access: Read-only on own rows in StudentExam and
                           StudentAnswer. Cannot access ModelAnswer.
                   CREATE ROLE student_role WITH LOGIN;

  GRANT SUMMARY PER TABLE
  -----------------------
  Table               instructor_role              student_role
  ------------------  ---------------------------  ---------------------------
  Departments         SELECT, INSERT, UPDATE, DEL  SELECT
  Track               SELECT, INSERT, UPDATE, DEL  SELECT
  TrackCourse         SELECT, INSERT, UPDATE, DEL  SELECT
  Course              SELECT, INSERT, UPDATE, DEL  SELECT
  Instructor          SELECT, INSERT, UPDATE, DEL  SELECT
  InstructorCourse    SELECT, INSERT, UPDATE, DEL  REVOKE ALL
  Student             SELECT, INSERT, UPDATE, DEL  SELECT (own row via RLS)
  StudentTrack        SELECT, INSERT, UPDATE, DEL  SELECT
  Questions           SELECT, INSERT, UPDATE, DEL  SELECT
  Choice              SELECT, INSERT, UPDATE, DEL  SELECT
  ModelAnswer         SELECT, INSERT, UPDATE, DEL  REVOKE ALL  <-- hidden
  StudentAnswer       SELECT, INSERT, UPDATE, DEL  SELECT, INSERT (own rows)
  Exams               SELECT, INSERT, UPDATE, DEL  SELECT
  ExamQuestion        SELECT, INSERT, UPDATE, DEL  SELECT
  StudentExam         SELECT, INSERT, UPDATE, DEL  SELECT (own rows via RLS)

  NOTE: Row-Level Security (RLS) must be enabled on Student, StudentExam,
        and StudentAnswer to restrict student_role to their own data only.
